# Hangman Game - CodeAlpha Task 1

## Description
A classic Hangman word-guessing game built with Python. Players guess letters to reveal a hidden word, with limited attempts. Includes error handling, game statistics, and replayability.

## Features
- ✅ Random word selection from a predefined word list
- ✅ Display hidden word with blanks
- ✅ Track guessed letters
- ✅ Limited attempts (6 wrong guesses)
- ✅ Input validation (single letters only)
- ✅ Win/Loss conditions
- ✅ Play again option
- ✅ Error handling for invalid inputs
- ✅ Game statistics (wins/losses)

## Technologies Used
- Python 3
- Loops and conditions
- String manipulation
- List operations
- Input validation
- Exception handling

## How to Play
1. Run the program: `python hangman.py`
2. A hidden word appears as dashes: `_ _ _ _ _`
3. Guess one letter at a time
4. Correct guesses reveal letters
5. Wrong guesses reduce attempts
6. Win by revealing all letters
7. Lose if attempts reach zero
8. Play again or exit
